# python斩

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

> 像背单词一样，把 Python 用成母语。

在线体验：**https://sycamore327.github.io/python-zhan/**

「python斩」是一个单页的 Python 词条学习工具：把函数、关键字、控制结构、运算符和常用概念做成词卡，配合「斩词挑战」、经典题库和模块图鉴，让零基础的人也能打开网页就开始学。

## 制作初衷

2026 年 10 月，我在学校组织了一个编程学习小组。群里大多数同学是第一次接触编程：装 Python、配编辑器、看英文文档，每一步都可能把人劝退。

于是想做一个**打开链接就能用**的东西，像背单词软件「百词斩」那样，每天斩几个词条：

- **不用装环境**：双击 HTML 或打开网页就能用，手机上也能直接看；
- **先会用，再深究**：每个词条给一句人话解释、一个最小例子和实际输出，不堆术语；
- **按「必须会 / 眼熟就行 / 先别学」分层**：不同阶段的人各取所需；
- **支持说人话搜索**：搜「我想输出」「我想排序」也能找到对应函数；
- **学完马上能练**：词库 → 斩词挑战 → 经典题 → 内置编程器，形成一个闭环。

这是给学习小组的第一份礼物，也希望能帮到更多刚起步的人。

## 里面有什么

- **139 个词条**：函数 73、控制结构 10、关键字 19、运算符 14、概念 20、变量 3
- **三种浏览方式**：难度（Lv.1–4）、首字母 A–Z、功能分类（15 类）
- **人话搜索**：函数名、中文描述、意图短语都能搜
- **斩词挑战**：每轮 10 题，三种题型（描述→词条 / 词条→用途 / 代码→输出），记录连对、正确率和错题
- **经典题库**：15 道由浅入深的练习，含思路、代码、逐行讲解和小挑战，可按难度、完成状态筛选
- **模块图鉴**：13 个常用模块，按「必须会 / 眼熟就行 / 先别碰」分层
- **内置 Python 编程器**：基于 Pyodide，代码只在浏览器本地运行，不上传服务器
- **手机优先**：词卡和答题层在手机上自动全屏
- **小彩蛋**：启动页和右下角各有一艘像素小飞船，戳戳看

## 快速开始

- **在线使用**：打开 <https://sycamore327.github.io/python-zhan/>
- **本地使用**：下载 `index.html`，双击用浏览器打开即可；内置编程器首次运行需要联网下载 Python 引擎，之后会走浏览器缓存

## 数据与隐私

学习记录（已掌握词条、答题统计、练习完成情况、模块已学）全部保存在浏览器的 `localStorage` 里，不会上传到任何服务器。清除浏览器数据或更换设备后，记录不会跟着走。

## 技术说明

- 单文件 `index.html`，内联 CSS / JavaScript / 数据，没有构建步骤，也没有后端
- Python 编程器使用 Pyodide 0.29.5（Python 3.13），从 CDN 懒加载
- 通过 GitHub Pages 部署，源为 `main` 分支根目录
